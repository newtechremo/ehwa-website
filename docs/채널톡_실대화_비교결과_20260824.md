## 최종 판정

로컬 자체 챗봇의 **답변 가능한 실대화 fallback은 0건**으로 개선됐다. 전체 158건 중 11건은 타 병원, 택시 승강장, 내부 프롬프트·로직, 근거 없는 지도 주장, 무의미 입력으로 근거 부족 또는 서비스 범위 밖이므로 보수적 fallback이 적절하다.

원문 대화 로그는 기본 비저장으로 보강했다. 2026-08-25 사용자가 기존 ChannelTalk의
전화번호·카카오·Walla URL·신청 문구를 그대로 유지하도록 확정했으므로 같은 내용의 별도 병원
재승인은 요구하지 않는다. 전체 실기기·스크린리더 매트릭스는 후속 검수로 두고, 자동 QA와
Production 다크 배포가 통과하면 전환할 수 있다. 다크 배포와 활성 배포 검증은 2026-08-25에
통과했고 현재 공개 URL은 자체 챗봇을 사용한다.

## 남은 fallback 11건

| 분류 | 질문 | 판정 |
|---|---|---|
| 근거 없는 사실 확인 | “안내데스크에서 내부 지도를 받는다”는 인용 | KB에 없으므로 추측 금지 |
| 내부 시스템 | 프롬프트, 현재 로직, 로직 수정 이유 3건 | 병원 안내 서비스 범위 밖 |
| 타 병원 | 세브란스 문의 3건 | 이대목동병원 KB로 확정 불가 |
| 위치 근거 부족 | 택시는 어디서 타는지 | 승강장 위치가 KB에 없음 |
| 시나리오·무의미 입력 | `버튼질문`, `AI로 질문 베이스...`, `햄버거` | 의도된 업무 질문이 아님 |

채널톡이 위 질문 일부에 자연스럽게 답했더라도 그 답 전체가 사실 근거는 아니다. 특히 채널톡은 동일한 지도 질문에 서로 다른 URL을 제시하거나 문서에 없는 동선을 만든 이력이 있다. 따라서 채널톡은 coverage 비교용이며, 이번에 유지하기로 확정한 전화·신청 URL·신청 문구와 Git KB를 사실 기준으로 사용한다.

## 해소한 근본원인

1. **예산 공유:** 자동 QA·replay가 500회를 소진해 사람 QA를 `daily_limit`으로 막았다. 현재 QA는 `qa-local` namespace·서버·preflight로 분리했다.
2. **전문 KB 입력:** 59문서 전체를 모델에 넣던 구조를 254청크 하이브리드 Top-K로 바꿨다.
3. **단일 청크 손실:** 한 문서의 위치·출발지·연결통로가 따로 뚨어지던 문제를 문서당 상위 4청크 병합으로 해소했다.
4. **후속 발화 목적지 소실:** `정문`, `주차장`, `현재 1층`, `엘베요`를 직전 목적지와 조합하도록 고쳤다.
5. **과거 질문 오염:** 독립적인 `접수→약→택시`에 과거 단어가 누적되던 문제를 명백한 후속 위치일 때만 history를 쓰도록 제한했다.
6. **구조화 위치 오선택:** 소아청소년과가 화장실 문서에도 등장하고 `1층`이 `11층`과 부분 일치하던 문제를 문서 우선순위와 정확한 층수 비교로 해소했다.
7. **핵심 정보의 모델 의존:** 이동 범위·신청·지도·진료과·화장실·접수·약·의뢰서·식당·건강검진·예약 준비를 짧은 답변과 구조화 절에 연결했다.
