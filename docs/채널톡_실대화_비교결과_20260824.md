## 자체 챗봇이 거절한 8건의 성격

- (채널톡은 답변) 지금  1층이에요
- (채널톡은 답변) 산부인과 별관 1층이에요
- (채널톡도 실패) 세브란스에서도 받을 수 있나요?
- (채널톡은 답변) 안내지침이 어디있어?
- (채널톡은 답변) 버튼질문 다시 알려줘
- (채널톡도 실패) 의료진에게 뭘 물어봐야할까
- (채널톡도 실패) 답변을 해줘
- (채널톡은 답변) 햄버거

- "햄버거"는 채널톡이 무의미한 에코를 내보낸 반면 자체는 범위 밖 거절 + 담당자 연결 — **거절이 올바른 동작**이다.
- "세브란스", "의료진에게 뭘 물어봐야 할까", "답변을 해줘"는 양쪽 다 실패(KB 밖·모호).
- "안내지침이 어디있어?"는 채널톡도 사실상 되물음이었다.

## 재생으로 발견해 수정한 자체 결함 (회귀 고정 완료)

1. "무료인가요" → 주차 FAQ/문서 가로채기 (부분포함 방향, FAQ·KB 양층)
2. "어떻게 이용할 수 있어요?" → 당일이용 FAQ / 이용대상 KB직답 (어미 겹침·커버리지 부풀림)
3. "병원에 도착해서 뭘 해야해?" → 외부이동 KB직답 원문 오출력 (표면 유사 0.627)
4. "진료 예약은 어떻게 해요?" → 편의지원 신청 KB직답 (KB 직답 게이트를 qScore 로 재설계)
5. "처음부터"·"버튼질문 다시" 메타 의도 → 웰컴 재안내로 처리 (채널톡 동작과 동일)
6. 위치만 말하는 후속 발화("지금 1층이에요") → 직전 주제를 그 위치 기준으로 안내 (프롬프트)
7. (환경) 서버리스 로그 유실 — `after()` 로 응답 후 기록 보장
