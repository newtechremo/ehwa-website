# [편의지원사업 기본정보] 여러 진료과 이용

## 예상 질문
- "하루에 진료과를 2군데 가는데 계속 같이 다녀주나요?"
- "오전에 내과 가고 오후에 정형외과 가는데 다 도와줘?"
- "여러 과 진료 볼 때도 끝까지 동행해 줘?"
- "진료과 옮길 때마다 직원이 바뀌나요?"
- "검사할 게 많은데 하루 종일 도와줄 수 있어?"
- "두 군데 예약했는데 연결해서 이용 가능해?"
- "진료 끝나고 다른 과 갈 때도 데려다줘?"
- "여러 군데 들러야 하는데 계속 같이 있어 주는 거지?"
- "하루 진료 일정이 복잡한데 전부 케어해 주나요?"
- "진료과 이동할 때마다 다시 신청해야 돼?"
