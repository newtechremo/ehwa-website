5. 챗봇 기능 구축
A. 대화형 챗봇 기본 구조 설계
1. 챗봇 운영 방식

1.1. 본 챗봇은 이용자의 문의 목적을 빠르게 파악할 수 있도록 선택형 대화 기반 구조를 기본으로 설계함
1.2. 메인 메뉴에서 주요 문의 항목을 명확히 제시하여, 고령자·장애인 이용자도 복잡한 입력 없이 원하는 정보를 확인할 수 있도록 구성

2. 메인 메뉴 구성

2.1. 초기 진입 시 다음과 같은 핵심 메뉴 제공

지원 범위 안내

이용 대상 안내

신청 방법 안내

비용 안내

운영 시간 및 위치 안내

2.2. 각 메뉴는 단일 선택 버튼 형태로 제공되며, 선택 시 해당 주제에 대한 안내 응답 노드로 연결됨

B. 대화 흐름 및 응답 구조
1. 정보 안내 응답

1.1. 지원 범위, 이용 대상, 비용, 운영 시간 및 위치 관련 문의는 **단일 응답 구조(Single Choice)**로 구성
1.2. 각 응답 후에는 ‘처음으로 돌아가기’ 선택지를 제공하여 반복 이용이 가능하도록 설계

2. 지식베이스 연동

2.1. 정형화되지 않은 질문에 대응하기 위해 지식베이스(Query Knowledge Base) 기반 응답을 함께 제공
2.2. 선택형 메뉴 외 질문에 대해서도 보완 설명이 가능하도록 구성하여 정보 접근성을 강화

C. 신청 연계 및 상담 채널 연결
1. 신청 방법 안내 흐름

1.1. ‘신청 방법’ 선택 시, 신청 절차 안내 후 상담 채널 선택 단계로 분기
1.2. 이용자가 선호하는 방식으로 상담을 진행할 수 있도록 다중 채널을 제공

2. 상담 채널 구성

2.1. 신청 채널은 다음과 같이 구성

카카오톡 상담

전화 문의

이메일 문의

병원 방문

2.2. 각 채널 선택 시 해당 방식에 대한 구체적인 안내 메시지를 제공하며, 응답 이후 다시 메인 메뉴로 복귀 가능하도록 설계

D. 접근성 및 사용성 고려 사항
1. 사용 편의성

1.1. 모든 선택지는 명확한 문구와 충분한 버튼 간격을 확보하여 오입력을 최소화
1.2. 대화 흐름은 깊이를 최소화한 2~3단계 이내 구조로 설계하여 피로도를 낮춤

2. 반복 이용 및 이탈 방지

2.1. 모든 주요 응답 노드에 ‘처음으로’ 기능을 제공하여 언제든 초기 상태로 복귀 가능
2.2. 불필요한 대화 종료를 방지하고, 지속적인 정보 탐색이 가능하도록 설계
