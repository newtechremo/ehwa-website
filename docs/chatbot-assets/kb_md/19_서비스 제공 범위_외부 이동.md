# [서비스 제공 범위] 외부 이동

## 예상 질문
- "집으로 데리러 와 줄 수 있나요?"
- "병원 갈 때 집에서부터 태워줘?"
- "진료 끝나고 집에 갈 때도 데려다주나요?"
- "자택 픽업 서비스는 안 해?"
- "병원 밖에서는 못 도와주는 거야?"
- "지하철역까지 마중 나와 줄 수 있어?"
- "이동 지원이 집에서부터 시작되나요?"
- "병원 도착해서만 도와주는 거야?"
- "구급차처럼 집으로 오는 서비스는 없어?"
- "원외 이동 지원은 불가능한가요?"

## 답변 가이드
서비스는 안전을 위해 '병원 건물 내부'로 한정되어 있어요.
진료 후 병원 안에 있는 약국까지 이동은 도와드리지만, 병원 밖 지하철역이나 외부 약국까지 나가는 건 동행이 어렵습니다.
