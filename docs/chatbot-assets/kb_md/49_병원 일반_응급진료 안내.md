# 1. 응급진료 운영 및 특징

## ① 운영 시간 및 대상
- **운영 시간:** 휴일 및 공휴일에 관계없이 **24시간 연중무휴** 진료합니다.
- **진료 대상:** 응급환자는 의료전달체계(1, 2차 의료기관 경유)와 관계없이, **진료의뢰서가 없어도** 바로 응급실에서 직접 진료가 가능합니다.
- **대기 시스템:** 무선통신망, 응급진료장비, 구급차 등이 24시간 대기하며 진료 공백을 최소화하고 있습니다.

## ② 응급실 접수 절차
1. **접수:** 응급실 내 '원무 접수·수납 창구'에 방문합니다.
2. **서류 제출:** 진료신청서, **건강보험증(또는 신분증)**을 제출합니다.
3. **확인:** 응급환자 네임지(Name tag)와 환자 팔찌를 발급받아 응급실 간호사실에 제출하면 진료가 시작됩니다.

## ③ 수납 안내 (비용)
- **수납 시기:** 귀가가 결정되면 일시에 수납합니다. (단, MRI, CT, 초음파 등 특수 검사는 실시 전 수납이 필요할 수 있습니다.)
- **결제 수단:** 모든 신용카드 납부가 가능합니다.
- **주의사항:** 건강보험 자격이 확인되지 않는 환자는 **보험 수가 전액(100%)을 본인이 부담**해야 합니다.

# 2. 응급증상 및 건강보험 적용 기준 (중요)

보건복지부 법률에 따라, 아래의 **'응급증상'** 또는 **'응급증상에 준하는 증상'**에 해당하지 않는 경증 환자는 **응급의료 관리료 등 보험 혜택을 받을 수 없습니다.** (진료비 본인 부담 증가)

## ① 법적 응급증상 (보험 적용 대상)
| 구분 | 세부 증상 |
| :--- | :--- |
| **신경학적** | 급성 의식장애, 급성 신경학적 이상, 구토·의식장애가 있는 두부 손상 |
| **심혈관계** | 심폐소생술이 필요한 증상, 급성 호흡곤란, 급성 흉통(심장질환), 심계항진, 박동이상 및 쇼크 |
| **중독/대사** | 심한 탈수, 약물·알코올 등 물질 과다 복용/중독, 급성대사장애(간부전, 신부전, 당뇨병 등) |
| **외과적** | 개복술이 필요한 급성 복통(복막염, 장폐색증 등), 광범위한 화상(18% 이상), 관통상, 개방성 골절, 절단 위험 혈관손상, 다발성 외상, 전신마취 응급수술 필요 증상 |
| **출혈** | 계속되는 각혈, 지혈이 안 되는 출혈, 급성 위장관 출혈 |
| **안과** | 화학물질에 의한 눈 손상, 급성 시력 소실 |
| **알러지** | 얼굴 부종을 동반한 알러지 반응 |
| **소아과** | 소아 경련성 장애 |
| **정신과** | 자신 또는 타인을 해할 우려가 있는 정신장애 |

## ② 응급증상에 준하는 증상 (보험 적용 가능)
| 구분 | 세부 증상 |
| :--- | :--- |
| **신경학적** | 의식장애 |
| **심혈관계** | 호흡곤란 |
| **외과적** | 화상, 급성 복증(배의 전반적 이상), 골절·외상·탈골, 기타 응급수술을 요하는 증상 |
| **출혈** | 혈관 손상 |
| **소아과** | 소아 경련 |
| **산부인과** | 성폭력으로 인하여 산부인과적 검사 또는 처치가 필요한 증상 |

# 3. 진료 후 퇴실 및 입원 절차

## ① 퇴실(귀가) 절차
1. 응급실 전문의 진료 후 퇴실 결정
2. 원무 창구에서 진료비 계산 및 영수증 발급
3. 영수증을 간호사에게 제출 후 약 수령
4. 다음 진료 사항 및 귀가 시 주의사항 상담 후 귀가

## ② 입원 절차
1. 응급실 전문의 진료 후 입원 결정
2. 담당 간호사로부터 입원 수속 안내 수령
3. 응급 수납 창구에서 입원 수속 완료 후 병동으로 입원
