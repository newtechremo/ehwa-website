# 2. 국가건강검진의 정의 및 목적
- **정의:** 모든 국민이 건강 위험 요인과 질병을 조기에 발견하여 치료받음으로써 건강한 삶을 영위하는 것을 목적으로 합니다.
- **근거:** '건강검진 기본법'에 의해 시행되며, 국가로부터 지정받은 검진 기관에서 받을 수 있습니다.
- **역할:** 이화건강검진센터는 국가 암 검진 기관 지정을 받아 지역사회 주민과 근로자의 건강 증진에 기여하고 있습니다.

# 3. 국가건강검진의 종류

| 구분 | 내용 |
| :--- | :--- |
| **일반검진** | 우리나라 사람에게 흔한 만성 질환을 조기에 발견하여 관리하기 위해 실시하는 검진입니다. |
| **생애전환기 검진** | 생애주기에 맞는 건강관리를 위해 일반 검진 대상자 중 **만 40세와 만 66세**에 실시하는 검진입니다. |
| **암 검진** | 암을 조기에 발견하여 치료율을 높이고, 급격히 증가하는 암 발생과 사망을 감소시키기 위한 검진입니다. |
