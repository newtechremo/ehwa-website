### 첨부파일 처리

`bin.channel.io` 직접 다운로드는 실패한다(HTTP 000). 해당 PDF는 저장소가 이미
동일 파일을 보유하고 있어 `attachments/` 로 복사하고 크기(111,437 bytes)와 sha256 을
`attachments.json` 에 기록했다. **첨부가 추가로 생기면 API 로는 받을 수 없으므로
채널톡 데스크에서 직접 내려받아야 한다.**

## 2. 챗봇 콘텐츠 원본 (콘솔 설정) 보존

대화 이력과 별개로, 채널톡 콘솔에 넣었던 콘텐츠는 원본 파일로 저장소에 있다.

- `[이대목동] 장애편의_콘텐츠_랜딩페이지&챗봇_251222.xlsx` — 버튼 시나리오·AI 지침·KB 원본
- `faq_upload_template_ko-260105-.xlsx` — FAQ 44건
- `챗봇 일반 kb.xlsx` — 병원 일반 KB
- `kb_md/` 60개 문서 — 위 자료를 변환한 RAG 지식문서
- 운영 Supabase: `kb_documents` 59 · `kb_chunks` 254 적재 완료

즉 **콘솔이 사라져도 챗봇 콘텐츠는 재구성 가능**하다.

## 3. API 로 받을 수 없는 것 (해지 전 데스크에서 처리)

Open API 에 해당 엔드포인트가 없다. 필요하면 **해지 전에** 채널톡 데스크에서 받는다.

- 상담 통계·리포트 (응답시간, 상담량 추이 등)
- 워크플로우/서포트봇 콘솔 설정 화면 자체
- 청구·결제 내역

경로: 채널톡 데스크 → 수신함 → 상담 목록 → 다운로드(“메시지를 포함한 파일” 옵션).
통계는 [데이터 센터] 메뉴에서 별도 다운로드.

## 4. 종료 절차 (순서 준수)

1. **백업 이중화** — `channeltalk-export/` 를 저장소 밖 안전한 위치에 복사한다.
   이 폴더는 git 에 없으므로 로컬 디스크 장애 시 함께 사라진다.
2. **데스크 수동 백업** — 위 3항(통계·설정·청구)을 받는다.
3. **해지** — 채널톡 구독 해지.

해지 후 `app/layout.tsx` 의 조건부 ChannelTalk 스니펫과 `app/admin/layout.tsx` 의
`ChannelIO` 숨김 코드를 제거한다. **그 전까지는 남겨 둔다** — 자체 챗봇 장애 시
`NEXT_PUBLIC_CHATBOT_ENABLED=false` 재배포만으로 채널톡으로 되돌릴 수 있는 유일한 경로다.
